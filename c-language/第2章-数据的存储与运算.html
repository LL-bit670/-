00为什么第 2 章最关键

第 1 章你只学会了「程序长什么样」，第 2 章开始回答一个更要命的问题：数据在电脑里到底是怎么存的？

这一章看起来像在讲一堆名词（整型、实型、字符型），其实是在给你后面所有章节打地基：

  • 不懂「整型只有 4 字节」→ 第 5 章写循环时会遇到莫名其妙的溢出
  • 不懂「float 存不准小数」→ 以后写判断语句会掉进 0.1+0.2 != 0.3 的坑
  • 不懂「字符本质是整数」→ 学字符串、数组、指针时会完全懵
一句话抓住全章C 语言里所有数据，最终都是内存里的一串 0 和 1。类型，只是你决定「用几位来解读这段 0/1」的方式。

01数据在内存里长什么样

三个基本单位

单位含义换算
位 bit一个 0 或 1，最小单位—
字节 Byte内存的编址单位，每个字节有独立地址1 B = 8 bit
字 WordCPU 一次能处理的数据长度（一般 4 或 8 字节）与机器有关

容量换算（注意是 1024，不是 1000）：

1 KB = 1024 B      1 MB = 1024 KB      1 GB = 1024 MB      1 TB = 1024 GB

二进制怎么换算（必须会手算）

二进制每一位的权重是 2 的幂：8 4 2 1（从右往左）。

  1 0 1 1   =  8 + 0 + 2 + 1 = 11(十进制)
  1 1 0 1 0 = 16 + 8 + 0 + 2 + 0 = 26(十进制)
  十进制 13 -> 13=8+4+1 -> 1 1 0 1
  十进制 20 -> 20=16+4 -> 1 0 1 0 0

常用的十六进制只是二进制的「缩写」：4 位二进制 = 1 位十六进制。

二进制 1011 0101  ->  十六进制 B5   (1011=B, 0101=5)

负数怎么存：原码、反码、补码

最高位当「符号位」：0 表示正，1 表示负。C 语言里负数一律用 补码 存放。

表示法规则以 -5 为例（8 位）
原码符号位 + 绝对值1000 0101
反码负数：符号位不变，其余取反1111 1010
补码负数：反码 + 11111 1011
为什么非要用补码因为补码能让「减法」直接用「加法」电路来算，硬件更简单。这也是为什么 1 + (-1) = 0 在补码下自动成立。
从这里推出一个后果补码把 0 的两种表示（正零负零）省出来了，所以 8 位补码能表示 -128 ~ 127（负数比正数多一个）。这个「多一个」的规律，到后面学溢出时会反复出现。

03整型数据

整型常量怎么写

进制写法例子十进制值
十进制直接写123123
八进制以 0 开头012383
十六进制以 0x 或 0X 开头0x1A26

八进制 0123 为什么是 83？1×64 + 2×8 + 3×1 = 83。十六进制 0x1A：1×16 + 10 = 26（A=10, B=11, C=12, D=13, E=14, F=15）。

经典陷阱int a = 010; 这个 a 是 8，不是 10。开头那个 0 不是给人看的，是给编译器看的。

整型变量：类型、字节数、取值范围

类型字节取值范围（有符号）
short2-32768 ~ 32767
int4-2147483648 ~ 2147483647
long4 (Windows) / 8 (Linux)见下注
long long8约 ±9.2×10^18
unsigned int40 ~ 4294967295
跨平台大坑（记住这条）long 在 Windows 上是 4 字节，在 64 位 Linux/macOS 上是 8 字节。所以「要存 64 位整数」时别用 long，一律用 long long，才可移植。
你上课用的是 Windows + Visual Studio / Dev-C++，所以：short=2、int=4、long=4、long long=8。

sizeof：别猜，让程序告诉你

sizeof 是运算符（不是函数），返回某个类型/变量占多少字节。

#include <stdio.h>

int main(void) {
    printf("char        : %d 字节\n", (int)sizeof(char));
    printf("short       : %d 字节\n", (int)sizeof(short));
    printf("int         : %d 字节\n", (int)sizeof(int));
    printf("long        : %d 字节\n", (int)sizeof(long));
    printf("long long   : %d 字节\n", (int)sizeof(long long));
    printf("float       : %d 字节\n", (int)sizeof(float));
    printf("double      : %d 字节\n", (int)sizeof(double));

    int a = 100;
    printf("sizeof(a)   : %d 字节\n", (int)sizeof(a));
    return 0;
}

这段代码你今晚亲手跑一遍，把结果抄在笔记本上。这是你 C 语言生涯里第一份「机器给出的答案」。

溢出：整数装不下会怎样

int a = 2147483647;   /* int 的最大值 */
a = a + 1;
printf("%d\n", a);    /* 输出 -2147483648 */

short b = 32767;
b = b + 1;
printf("%d\n", b);    /* 输出 -32768 */

不是报错，也不是变成 2147483648，而是「绕回去」了——这就是补码的必然结果。最大值加 1 变成最小值，像时钟走过 12 点回到 1 点。

04实型数据（浮点型）

实型常量两种写法

3.14        /* 小数形式 */
.5          /* 等于 0.5 */
5.          /* 等于 5.0 */
3.14e5      /* 指数形式：3.14 × 10^5 = 314000.0 */
1.5e-3      /* 1.5 × 10^-3 = 0.0015 */
指数形式的硬性规则① e 前面必须有数字（e5 是错的，要写 1e5）；② e 后面必须是整数（1.2e1.5 是错的）；③ e 前后不能有空格。

规范化指数形式：小数点前只有一位非零数字。314000.0 的规范写法是 3.14e5。

float 与 double 的精度

类型字节有效数字说明
float4约 6~7 位单精度
double8约 15~16 位双精度，默认首选
long double8 或 16更长用得少

存储方式遵循 IEEE 754 标准：符号位 + 指数位 + 尾数位。float 是 1+8+23，double 是 1+11+52。尾数位越多，能记的有效数字越多。

为什么 0.1 + 0.2 != 0.3

#include <stdio.h>

int main(void) {
    float a = 0.1f, b = 0.2f;
    if (a + b == 0.3f)
        printf("相等\n");
    else
        printf("不相等！(a+b = %.10f)\n", a + b);
    return 0;
}

0.1 在二进制里是无限循环小数，存进 float 只能存一个近似值，两个近似值相加误差就露出来了。结论：浮点数永远不要用 == 比较大小，要比较就用差值判断：

if (fabs(a + b - 0.3) < 1e-6)   /* 需要 #include <math.h> */
    printf("可以认为相等\n");

05字符型数据

字符常量和转义字符

字符常量用单引号括起来：'a'、'A'、'0'、' '。注意 '\0' 和 '0' 是两回事。

转义字符含义
\n换行
\t制表符（Tab）
\\反斜杠本身
\'单引号
\"双引号
\0空字符（ASCII 码 0），字符串结束标志
\ddd1~3 位八进制数表示的字符，如 \101 是 'A'
\xhh十六进制数表示的字符，如 \x41 是 'A'

关键认知：字符本质就是整数

计算机里没有「字母」这种东西，只有 ASCII 码。char 占 1 字节，存的其实是那个数字。

字符ASCII记忆点
'0' ~ '9'48 ~ 57连续
'A' ~ 'Z'65 ~ 90连续
'a' ~ 'z'97 ~ 122连续
' '32空格
'\n'10换行
最值钱的三个数'0'=48、'A'=65、'a'=97。而且 'a' - 'A' = 32，所以大小写转换就是加减 32。
#include <stdio.h>

int main(void) {
    char c = 'A';
    printf("%c 的 ASCII 码是 %d\n", c, c);   /* A 的 ASCII 码是 65 */

    c = c + 1;                                /* 字符可以参与算术运算 */
    printf("加 1 后变成 %c\n", c);             /* B */

    char small = 'a';
    small = small - 32;                       /* 小写转大写 */
    printf("小写 a 转大写：%c\n", small);       /* A */

    printf("'0' 的值是 %d，不是 0 本身\n", '0'); /* 48 */
    return 0;
}
务必区分'0' 是字符，值是 48；0 是整数零。写成 int x = '0'; 的 x 是 48，不是 0。这是新手第一大混淆点。

06算术运算符与表达式

五个运算符

运算符含义注意
+ - *加 减 乘无坑
/除两个整数相除，结果截断取整
%求余只能用于整数，结果符号跟着被除数
5 / 2        /* = 2  不是 2.5，小数部分直接丢掉 */
5.0 / 2      /* = 2.5  有一个是浮点，就按浮点算 */
5 % 2        /* = 1 */
-5 % 3       /* = -2  符号跟被除数 -5 走 */
5 % -3       /* = 2 */
5.5 % 2      /* 编译错误！% 不能用在小数上 */
最容易错的写法想算平均值：int avg = (a + b) / 2; 如果 a+b 是奇数，结果会被截断。要精确就得写 (a + b) / 2.0，或者提前把变量换成 double。

自增自减：前缀与后缀

int i = 5;
int a = i++;   /* 后缀：先把 5 给 a，i 自己再变 6  →  a=5, i=6 */
int j = 5;
int b = ++j;   /* 前缀：j 先变 6，再把 6 给 b       →  b=6, j=6 */

口诀：++ 在前，先加后用；++ 在后，先用后加。

类型转换

自动转换（小范围 → 大范围，安全）：

char / short  ->  int  ->  unsigned  ->  long  ->  double
                                      (浮点级别最高)

1 + 2.5   /* int 自动升级为 double，结果是 3.5 */

强制转换（你说了算，可能丢数据）：

(int)3.9      /* = 3，直接砍掉小数，不是四舍五入 */
(int)(5.0/2)  /* = 2 */
(double)5/2   /* = 2.5，注意括号位置，只转了 5 */
观察这组的区别(double)5 / 2 得 2.5，因为 5 先变成 5.0；(double)(5 / 2) 得 2.0，因为里面已经先算出整数 2 了。括号的位置决定一切。

07今晚练习（先做，再看答案）

规则：先自己写在纸上算，不许直接看答案。做错的题在旁边打个记号，明天再回头看一遍。

1写出下列各式的结果：
(1) 7 / 2          (2) 7 % 2         (3) 7.0 / 2
(4) (float)7 / 2   (5) (float)(7 / 2) (6) -7 % 2
看答案

(1) 3　整数除法截断，小数位丢掉。
(2) 1　7 = 2×3 + 1。
(3) 3.5　7.0 是 double，按浮点运算。
(4) 3.5　7 先转成 float 再除。
(5) 3.0　括号里已经先算出整数 3，再转成 float，所以是 3.0。
(6) -1　C99 起余数符号跟随被除数，-7 = 2×(-4) + 1？不对，重算：-7 / 2 = -3（截断），-3×2 = -6，-7 - (-6) = -1，所以结果是 -1。

2下面三个变量的值分别是多少？
int a = 010;
int b = 0x10;
int c = 10;
看答案

a = 8（八进制 010 = 1×8 + 0 = 8）
b = 16（十六进制 0x10 = 1×16 + 0 = 16）
c = 10（普通十进制）

3这段代码输出什么？
short s = 32767;
s = s + 1;
printf("%d\n", s);
看答案

-32768。short 上限 32767，加 1 越界后按补码绕回到最小值，不报错。这就是整数溢出。

4下面 printf 各输出什么？
char c = 'a';
printf("%c\n", c);
printf("%d\n", c);
printf("%c\n", c - 32);
printf("%d\n", '0');
看答案

依次是：a、97、A、48。
第 3 行：'a' 是 97，减 32 得 65，%c 输出 65 对应的字符就是 'A'。
第 4 行：'0' 这个字符的 ASCII 码是 48，不是数字 0。

5下面这段代码会输出"相等"吗？为什么？
float x = 0.1f;
if (x == 0.1) printf("相等\n"); else printf("不相等\n");
看答案

不相等。0.1f 是 float（4 字节），而 0.1 是 double（8 字节），两者精度不同，二进制表示也不同，比较时不等。就算两个都是 float，0.1 本身也存不准。结论：浮点数不要用 == 比较。

6求 i、j、a、b 的最终值：
int i = 3, j = 3;
int a = i++;
int b = ++j;
看答案

a = 3（后缀：先赋值，i 再变 4 → i = 4）
b = 4（前缀：j 先变 4，再赋值 → j = 4）

7下列哪些写法是错的？为什么？
(1) 3.2e5     (2) e5     (3) 1.2e3.5     (4) .5e-3
看答案

(1) 合法，等于 320000.0　(2) 错，e 前面必须有数字
(3) 错，e 后面必须是整数，不能是 3.5　(4) 合法，等于 0.0005，.5 等同于 0.5

9为什么要用补码存负数？用自己的话说一遍。
看答案

因为补码能把减法变成加法，CPU 不需要单独做一套减法电路，硬件更简单；同时补码让 0 只有一种表示，能多表示一个负数（-128）。

10（动手题）输入一个三位整数，输出它的百位、十位、个位数字。提示：用 / 和 %。
看答案
#include <stdio.h>

int main(void) {
    int n;
    printf("请输入一个三位整数: ");
    scanf("%d", &n);

    printf("百位: %d\n", n / 100);
    printf("十位: %d\n", n / 10 % 10);
    printf("个位: %d\n", n % 10);
    return 0;
}

这题是「整数除法 + 求余」的经典组合，以后写题目会反复用到，值得现在就记熟。
